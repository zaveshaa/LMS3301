# Практическая работа №3. Цикл for

Материалы практики №3 (6 заданий + 7-е на дополнительный балл).

## Где что лежит

- `practice3.tex` — текстовая (LaTeX) копия задания, включая формулу задания 4
  и вставку картинки с вариантами функции `y(x)`.
- `../../static/practice3/formulas.png` — картинка с вариантами `y(x)`
  (извлечена из исходного PDF). Отдаётся приложением по адресу
  `/static/practice3/formulas.png`.

## Как это попало в LMS

- Содержание практики и задач хранится в базе `src/lms.db`.
- Резервная копия для пересоздания (`LMS_DEMO=1`) — структура `PRACTICE3`
  в `src/db.py`.
- В условиях задач можно писать формулы в LaTeX между `$...$` (строчная) или
  `$$...$$` (выключная) — они рендерятся MathJax.
- Картинки вставляются в условие в виде `![подпись](/static/...png)`.

## Сборка LaTeX

```bash
cd src/content/practice3
pdflatex practice3.tex
```
